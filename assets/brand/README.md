# OpenSW brand

Use **OpenSW** with capital **S** and **W**. Application names are OpenSW Files, OpenSW Projects, OpenSW Notes, and OpenSW Chat.

`OpenSW-logo.png` is the original transparent primary logo created for this project with the built-in image generation tool. The app copy lives at `web/public/OpenSW-logo.png`.

Generation brief: an original indigo open-gateway emblem with a restrained mint accent, paired with the exact wordmark **OpenSW**, clean contemporary typography, transparent background, and no imitation of the commercial products' marks. The [complete prompt and generation mode](prompt.txt) are preserved with the asset.

The logo does not establish trademark clearance. The apps use independent branding and interfaces.
